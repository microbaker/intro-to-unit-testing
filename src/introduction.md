# Introduction

Unit testing is one of the highest-leverage practices available to C++ developers. Done well, it catches defects early, documents intended behavior, and makes refactoring safer.

This book is a practical guide to writing effective unit tests with the Google Test framework. It assumes you are an intermediate C++ developer comfortable with classes, templates at a basic level, and CMake. Every important technique is shown with complete, compilable examples.

You will learn how to:

- Set up a modern Google Test project
- Choose between `ASSERT` and `EXPECT`
- Write clear failure messages
- Use fixtures and parameterized tests
- Test private code without destroying encapsulation
- Measure coverage and integrate tests into CI
- Apply unit testing to security-relevant logic
- Follow practices that keep a suite fast and maintainable

The final project gives you a chance to assemble everything into a realistic test suite.

Start with Chapter 1 and build the starter project. From there the examples accumulate.
